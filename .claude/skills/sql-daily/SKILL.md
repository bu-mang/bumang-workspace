# /sql-daily — 아침 SQL 루틴

**프로토콜 정본은 `sql-dojo/CLAUDE.md` 의 "루틴 프로토콜"** 이다. 이 스킬은 진입점일 뿐, 규칙을 여기에 복제하지 않는다.

## 절차

1. `sql-dojo/CLAUDE.md` 를 읽는다 (원칙·세트 구성·채점·기록 절차).
2. "1. 준비" 블록의 커맨드를 한 번에 실행한다 (DB 기동 · 복습 예정 토픽 · 최근 로그 · 미해결 오답 · 은행 목록).
3. 인자(`$ARGUMENTS`)를 "2. 세트 구성" 의 인자 해석 규칙대로 적용해 오늘 세트를 정한다. 인자 없으면 기본 3문제.
4. 세트를 한 줄로 예고한 뒤(예: `오늘: 복습 B7 · 신규 A3 · 이론 M6`), **첫 문제만** 내고 턴을 끝낸다.
5. 유저 답 → 채점 → 피드백 → 다음 문제. 마지막 문제까지.
6. "5. 기록" 을 빠짐없이 수행하고 오늘 결과를 표로 요약, 내일 포커스 한 줄.

## 지킬 것
- 정답·해설을 답 전에 노출하지 않는다. 틀리면 힌트 먼저.
- 유저 SQL 은 scratchpad 에 파일로 저장해 `sql-dojo/scripts/check.sh` 로 채점한다 — 눈대중 채점 금지.
- 하위 레포 커밋은 하지 않는다. 마무리에 `/commit-all` 안내만.
