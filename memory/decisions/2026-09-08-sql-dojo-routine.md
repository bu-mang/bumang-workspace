# 학습 루틴도 "하위 레포 + 루트 스킬" 패턴으로 — sql-dojo 개설

## 결정
매일 아침 SQL 훈련(SQLD 대비 + 활용능력)을 위해 **`sql-dojo/`** 를 워크스페이스 하위 **독립 레포**로 만들고, 진입점은 루트 스킬 **`/sql-daily`** 로 둔다. 프로토콜 정본은 `sql-dojo/CLAUDE.md`, 스킬은 얇은 진입점.

## 이유
- 학습 자료(문제 은행·오답·숙련도)는 파일로 쌓여야 하고 git 히스토리가 곧 학습 기록이 된다 → 기존 프로젝트와 같은 레포 패턴이 맞다.
- 루틴은 루트(지휘소)에서 시작하므로 스킬은 루트에, 규칙은 현장(`sql-dojo/CLAUDE.md`)에 — [[2026-07-06-thin-lens-boundary]] 그대로.
- 실행 엔진은 **PostgreSQL**(스택 시그니처 유지). SQLite 는 ROLLUP/CUBE 가 없어 SQLD 활용 범위를 못 덮고, Oracle 은 무겁다. Oracle 방언은 차이표 + 이론 카드로.
- 세부 결정(채점 방식·Leitner·은행 성장 규칙)은 `sql-dojo/PLANNING.md` 가 정본 — 여기 복제하지 않는다.

## 함정
