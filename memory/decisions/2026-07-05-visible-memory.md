# 루트를 지휘소로, 비서의 뇌를 `memory/`에 구축

**결정**: 하위 레포로 `cd` 들어가지 않고 이 루트에서 모든 작업을 하며, 총체적 의사결정을 **보이는 `memory/` 폴더**에 누적한다. 숨은 네이티브 메모리(`~/.claude/projects/.../memory/`)는 정본을 가리키는 **포인터로 격하**.

**이유**: 유저가 결정 기록을 **눈으로 보고 관리**하길 원함. 네이티브 메모리는 자동 로드되지만 작업 폴더 밖에 숨어 있어 부적합.

**대가(2026-07-26 인식)**: "보이게" 만드느라 한 파일에 몰아넣는 monolith 구조를 택했고, 그 결과 **선택적 로드가 불가능**해졌다(결정 1개가 필요해도 10개를 다 읽음). 회사 camfit 네이티브 메모리는 반대로 33개 파일 + 인덱스라 필요한 것만 읽힌다. → 이 대가를 갚은 것이 [[2026-07-26-memory-sharding]].

**상태**: 확정 · 진행 중 (구조는 2026-07-26에 인덱스+샤딩으로 개선).
